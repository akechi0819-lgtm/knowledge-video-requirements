# 网页预览的数据保存与恢复

浏览器通过 `web/project-storage.js` 接入 IndexedDB 本机项目列表。点击“保存到本机”会导出当前项目并等待本地事务成功。空闲时每 30 秒自动保存，失败信息显示在保存控件旁。清除站点数据会删除本机副本。

网关为每个匿名浏览器创建独立 Docker 容器和临时卷。容器内 DSH、模型凭据、工作区及任务互相隔离。网关 Cookie 保留 24 小时，临时实例到期后删除，用户可以通过本机副本恢复项目。模型 Key 只在该实例的内存中保存，恢复到新实例后需重新填写。

`POST /bohack/api/projects/export?threadId=...` 返回 `{ok,snapshot}`。快照格式为 `{version:1,files:[{path,data}]}`，内容使用 base64。制作运行时拒绝导出，同项目请求串行执行。

`POST /bohack/api/projects/import` 接收快照，返回新的 `thread.id`。恢复后使用新 ID 访问业务接口。项目包不包含服务端指令、设置、私有模型凭据和可重新生成的渲染中间图片，保留原始资料、蓝图、制作源码、配音与成片。符号链接和特殊文件拒绝导出。

导入请求上限为 100 MiB，浏览器本机存储受站点配额限制。界面明确提示保存或恢复失败。临时项目按配置到期清理，正在制作或处理请求的项目跳过本轮清理。

相关回归测试位于 `test/multiuser-browser.test.js`、`test/multiuser.test.js` 和 `test/project-exchange.test.js`。真实服务器验收另外验证关闭浏览器后取片、临时项目清理以及从本机恢复成片。
