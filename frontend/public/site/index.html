没有美洲，
火锅会少些什么？

以一顿现代火锅做想象实验：把辣椒、土豆、番茄依次点亮、撤走，再讲美洲原住民的种植选育与跨洲传播。旁白逐字保留，段落顺序严格按蓝图。

01Requirement

需求对话

像创作搭档一样用中文自然对话，弄清你想让观众看懂什么。信息足够就不追问；只有缺口会让蓝图讲偏时，才问一个最关键的问题。

  • 不把模型猜测写成要求
  • 本地长文场面检索
  • 用户改口即覆盖
交接产物 · 视频需求.md + 资料索引.json
02Blueprint

分段蓝图

按顺序排列的视频大纲，每段都写清讲什么、依据哪些事实、画面意图是什么。你在制作前确认，也可以随时提出修改。

  • 每段可被定位
  • 保留明确要求
  • 确认后才制作
交接产物 · 定稿蓝图.md + production.json
03Video Agent

视频 Agent

独立视频 Agent 按蓝图和已确认素材编写每段 HTML / CSS / JavaScript，调用配音、预览、渲染、质检与提交工具完成成片；也可切换原结构化模式。

  • 神经配音 · 逐词时间戳
  • 逐段抽帧质检
  • 素材账本
