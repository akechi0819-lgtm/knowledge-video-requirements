# 蓝图：没有美洲，火锅会少些什么？

- **版本：** v2
- **状态：** 待确认
- **引擎：** DSH agent 会话 · preset blueprint · 真实调用
- **来源：** inbox/需求.md

## 一、整体内容

- **核心意思：** 以一顿现代火锅做"想象实验"：把老家在美洲的食材（辣椒、土豆、番茄）依次点亮、标名、撤走，看这顿饭少了什么；再讲这些食材背后的美洲原住民种植选育，以及跨洲传播（大航海时代）如何把相隔遥远的餐桌连起来；最后把三样食材端回来，落回"一顿火锅，也藏着世界交流史"。
- **目标观众：** 对美食、历史与植物感兴趣的大众观众（朋友吃饭聊天的语境）
- **叙事顺序：** 餐桌想象实验 → 依次撤走三样食材 → 美洲原住民选育 → 跨洲传播 → 回归餐桌（问题—实验—答案—机制—回扣）

## 三、分段蓝图

### B01｜餐桌提问

**讲什么：** 这桌火锅的红油、土豆片、番茄，对应辣椒、土豆、番茄三种老家在美洲的食材；把它们挑出去，桌上会空出辣劲、脆口、酸甜几块熟悉的味道。

**关键事实：** 辣椒、土豆、番茄、豆腐、青菜凑成这桌火锅，其中辣椒、土豆、番茄的老家都在美洲。；把辣椒、土豆、番茄这三样挑出去，桌上会空出辣劲、脆口、酸甜几块熟悉的味道。

**画面意图：** 使用上传原图「火锅餐桌.png」：观众能看到原图上的红汤与辣椒、土豆、番茄三样食材，并随旁白抛出问题。

**旁白：** 先别急着下筷子。看这桌火锅，汤里翻着红油，土豆片切得薄薄的，番茄还带着汁。要是把那些老家在美洲的食材都挑出去，你猜，桌上会空出哪几块？

### B02｜依次点亮、标名、撤走辣椒、土豆、番茄

**讲什么：** 依次撤走辣椒、土豆、番茄后，红汤少了辣劲、这一筷子少了脆、锅底少了酸甜；豆腐和青菜还在，却补不齐这三样美洲作物撑起的味道。

**关键事实：** 辣椒、土豆、番茄、豆腐、青菜同摆一桌，撤走前三样，辣劲、脆口、酸甜三块味道就空了。；豆腐、青菜还在桌上，却补不齐辣椒、土豆、番茄这三样美洲食材撑起来的味道。

**画面意图：** 观众看到辣椒、土豆、番茄按旁白依次标亮、消失，豆腐和青菜留在桌上，形成少了三样美洲食材的对比。

**旁白：** 先拿走辣椒，红汤就少了那股熟悉的辣劲。再撤掉土豆片，这一筷子脆的没了。最后端走番茄，酸甜的锅底也得换个做法。豆腐和青菜还在，怎么这顿饭，吃着已经不太一样了？

### B03｜美洲原住民种植选育：聚焦安第斯土豆

**讲什么：** 这些作物不是凭空出现在盘子里，而是美洲原住民在欧洲人横渡大西洋之前就种植、选育出来的；以土豆为例，安第斯山区的农人培育出许多适应不同生长条件的品种，今天这一片背后是好几代人的经验。

**关键事实：** 早在欧洲人横渡大西洋之前，美洲原住民就已经在种植、挑选适合当地的作物。；安第斯山脉的农人培育出许多适应不同生长条件的土豆品种，今天这一片背后是好几代人的经验。

**画面意图：** 观众看到山地与不同形态的土豆摆在一起，表达安第斯山区的农人培育出适应不同生长条件的品种；画面只说欧洲人到来前已种植、选育，不配海拔或年代。

**旁白：** 答案藏在种这些作物的人手里。早在欧洲人横渡大西洋之前，美洲原住民就已经在种植、挑选适合当地的作物。拿土豆来说，安第斯山区的农人，培育出了许多适应不同生长条件的品种。我们今天夹起的这一片，背后是好几代人的经验。

### B04｜跨洲传播概念示意

**讲什么：** 跨洋航行把相隔遥远的餐桌连起来：土豆在爱尔兰成了家常食物，番茄融进了意大利菜，辣椒走进了亚洲的厨房——地图上是几条不同的线，落到生活里是一个个地方的人学着种、试着做，再把新味道留下来。

**关键事实：** 土豆、番茄、辣椒分别进了爱尔兰、意大利、亚洲的厨房，是三条不同的去向。

**画面意图：** 观众看到一张真实轮廓的世界地图：美洲与爱尔兰、意大利、亚洲依次高亮，并分别标出土豆、番茄、辣椒；不画具体年代、精确航线或箭头，画面注明"概念示意"。

**旁白：** 后来，跨洋航行把相隔遥远的餐桌连了起来。土豆在爱尔兰成了家常食物，番茄融进了意大利菜，辣椒也走进了亚洲的厨房。地图上看是几条线，落到生活里，却是一个个地方的人，学着种、试着做，再把新味道留下来。

### B05｜三样食材回归

**讲什么：** 三样端回来后，锅还是那口锅，但这一桌菜已经不一样了；这一口熟悉的味道，最早是美洲原住民种出来的，一顿火锅里也藏着世界交流史。

**关键事实：** 辣椒、土豆、番茄、豆腐、青菜重新凑成一桌，锅还是那口锅，这一桌菜却已经不一样了。；这一口熟悉的味道，最早是美洲原住民种出来的——一顿火锅，也藏着世界交流史。

**画面意图：** 回到上传原图「火锅餐桌.png」：观众看到辣椒、土豆、番茄三样食材回归归位，结尾落字幕"一顿火锅，也藏着世界交流史。"

**旁白：** 好，把辣椒、土豆片和番茄都端回来。锅还是那口锅，再看这桌菜，是不是有点不一样了？下次等汤烧开的时候，你也可以问问同桌的人：这一口熟悉的味道，最早是谁种出来的？
